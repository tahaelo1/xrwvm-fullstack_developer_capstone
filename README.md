# \# Dealerships Review Portal

# 

# \## Project Name: National Car Dealership Review Website

# 

# \### Developer: Taha Elorani

# 

# \### Description

# A full-stack web application that allows customers to view car dealerships across the United States, read reviews, and submit their own reviews after logging in.

# 

# \### Technologies Used

# \- Django (Python)

# \- React.js

# \- Node.js + Express

# \- MongoDB

# \- SQLite

# \- IBM Code Engine (Sentiment Analysis)

# \- Docker

# \- GitHub Actions (CI/CD)

# 

# \### Features

# \- View all dealerships nationwide

# \- Filter dealerships by state

# \- View reviews for each dealership

# \- Add reviews (authenticated users)

# \- Sentiment analysis on reviews

# \- Admin portal for managing car makes and models
